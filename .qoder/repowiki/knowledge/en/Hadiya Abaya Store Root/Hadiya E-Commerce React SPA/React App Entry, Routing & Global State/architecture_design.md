- `main.jsx` is the Vite entry: renders `<App />` inside `React.StrictMode`, then conditionally registers a Service Worker (`/sw.js`) in production via `import.meta.env.PROD`.
- `App.jsx` composes the provider tree (`ToastProvider` → `ProductProvider` → `WishlistProvider` → `CartProvider` → `BrowserRouter`) and defines a `MainLayout` that mounts `Header`, `Footer`, `MobileBottomNav`, drawer/modal overlays (`CartDrawer`, `WishlistDrawer`, `SearchModal`, `MobileMenuDrawer`), and a `Routes` table mapping `/`, `/shop`, `/product/:id`, `/cart`, `/checkout`, `/order-success`, `/admin` to page components under `pages/`.
- Shared UI chrome lives in `components/` (Header, Footer, ProductCard, Cart/Wishlist/Search/Mobile drawers) and is reused across pages; an admin route bypasses header/footer/nav.
- Global mutable state is centralized in `context/`: each context file follows the same pattern — creates a `createContext`, exports a `*Provider` wrapping children with `useState` + `useEffect` syncing to a dedicated `localStorage` key (`hadiya_cart_items`, `hadiya_products`, etc.), exposes CRUD helpers, and re-exports a custom `useXxx` hook.
- Static product catalog is defined in `data/products.js` as `initialProducts` and hydrated into `ProductContext`; `utils/cloudinary.js` holds image upload helpers used by the admin flow.
- Styling is flat CSS imported once in `App.jsx` (`styles/style.css`, `styles/animations.css`); no CSS-in-JS or per-component stylesheets.
