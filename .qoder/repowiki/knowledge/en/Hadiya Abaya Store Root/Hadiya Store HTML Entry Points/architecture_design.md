Each file is a self-contained HTML document served directly by the web server. `index.html` is the only SPA entry: it mounts a React application via `<script type="module" src="/src/main.jsx">` into a `#root` div. The other four files (`shop.html`, `product.html`, `cart.html`, `admin.html`) are traditional multi-page templates that load shared CSS (`css/style.css`, `css/animations.css`) and JS modules (`js/app.js`, `js/cart.js`) via deferred scripts; they share identical header/footer/mobile-nav/drawer markup so the same client-side code renders consistent UI across pages. `admin.html` is fully self-contained — its tab navigation, modal, and CRUD logic are implemented inline in a `<script>` block with no external dependencies, making it a standalone admin dashboard. Dependency direction is one-way: all pages depend on shared assets under `css/` and `js/`; there is no cross-page JS communication beyond `localStorage`-backed cart/wishlist state.
