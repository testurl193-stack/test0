The root holds the single Vite-based build pipeline (`vite.config.js` with `@vitejs/plugin-react`) that compiles the `react_app` child into a static bundle. The `html_entrypoints` child provides the `index.html` shell (and marketing/admin pages) that boot the React app, while `static_assets` contributes CSS, images, and a service worker consumed by those pages. `vercel.json` centralizes production behavior: a catch-all rewrite to `/index.html` enables client-side routing, and path-based `headers` rules set immutable caching on `/assets`, `/images`, JS/CSS/woff2 files plus security headers on all responses. The top-level `package.json` is the shared dependency surface declaring only the runtime deps (`react`, `react-dom`, `react-router-dom`) and dev tooling (`vite`, `@vitejs/plugin-react`) used by every child.
